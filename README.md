## 🧭 Featured Project

### 走部落 TribeWalk｜AI 輔助全端專題

以臺灣原住民族部落文化旅遊為主題，從主題發想、資料蒐集、<br>
使用者角色、功能與操作流程、網站內容及介面方向，<br>
到 AI 協作開發、功能測試、問題修正與 <br>
GitHub 文件整理，皆由本人獨立統籌執行。<br>

**主要功能**

- 景點搜尋與分類篩選、完整遊程及內容瀏覽
- 會員註冊、登入與不同角色權限流程
- 景點評論、揪團申請與審核、留言板及旅伴互評
- 管理後台、表單防呆、API 回傳與資料庫應用

**我的角色**

- 需求與使用者角色拆解
- 網站架構、功能流程及介面方向規劃
- AI 協作開發、提示詞溝通與功能驗證
- 測試紀錄、問題修正與 README 文件整理

**使用技術與工具**

`HTML5` `CSS3` `JavaScript` `PHP` `MySQL` `SQLite` `Bootstrap` `Figma` `Git` `GitHub` `ChatGPT` `Claude`
